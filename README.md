# My Gym Coach

Personal workout app for working towards a first pull-up: a 3D demo of each exercise, set tracking and a rest timer.

It is a static site with no build step: `index.html` loads `styles.css`, `figure3d.js` (the 3D demo), `exercises.js` (the workout, with tips and common mistakes) and `app.js`. Add it to your phone home screen to open it full screen.
